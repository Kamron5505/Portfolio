# Портфолио — Kamron Fazilov

Персональный сайт **Камрона Фазилова**, frontend-разработчика из Ташкента.
Три языка: EN (`/`) · UZ (`/uz`) · RU (`/ru`).

**Стек:** Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS ·
Three.js / React Three Fiber · GSAP · Serwist (PWA).

Базы данных у проекта нет: все страницы статические, контент лежит в коде.

## Быстрый старт

```bash
npm install
npm run dev
```

Сайт — <http://localhost:3000>. Никаких переменных окружения для запуска не
нужно.

## Где править контент

Правки делаются в коде и выкатываются пушем в `main` — Vercel пересобирает сайт
автоматически.

| Файл | Что внутри |
| --- | --- |
| `src/lib/data.ts` | Домен, имя, роль, email, фото, резюме, соцсети, проекты, навыки |
| `src/lib/i18n.ts` | Все тексты на трёх языках: заголовки секций, описания, SEO-заголовки |

Английские тексты живут в `data.ts` и переиспользуются в `i18n.ts`, чтобы одни
и те же строки не расходились. `src/lib/content.ts` собирает из этих констант
готовые к рендеру объекты — секции не знают, откуда взялся контент.

### Резюме

Положите PDF в `public/Kamron_Fazilov_CV.pdf` (путь задан в `SITE.cv`).
`content.ts` проверяет, что файл на месте: если его нет, кнопки «Скачать CV» не
рендерятся, ссылка не попадает в `sitemap.xml` и в JSON-LD. Битой ссылки на
резюме на сайте не появится никогда.

## SEO

Всё строится от одного значения — `SITE.url` (`src/lib/data.ts`), которое можно
переопределить переменной `NEXT_PUBLIC_SITE_URL`. `normalizeSiteUrl()` приводит
его к https без хвостового слэша и отбрасывает адреса preview-деплоёв, поэтому
технический домен хостинга не может попасть в canonical.

От этого значения работают: `canonical`, `hreflang` (en/uz/ru + `x-default`),
`og:url`, `sitemap.xml`, `robots.txt` и JSON-LD (`Person`, `WebSite`,
`ProfilePage`, `BreadcrumbList`) — в одной и той же форме URL, без дублей.

Соцкартинка генерируется на лету из `src/lib/og.tsx`: отдельная на английский
корень и отдельная на каждую локаль (группы маршрутов не наследуют метафайлы
друг у друга, без второго файла у `/uz` и `/ru` не было бы `og:image`).

### Переменные окружения

Обязательных нет. Единственная поддерживаемая описана в `.env.example`:

| Переменная | Зачем |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Канонический домен. Не задана — берётся `CANONICAL_SITE_URL` из `src/lib/data.ts` |

## Живой чат

Плавающая кнопка в правом нижнем углу на всех страницах. Канал общий:
посетители видят сообщения друг друга. Транспорт — опрос `/api/chat` раз в
несколько секунд (на serverless WebSocket не живёт); в фоновой вкладке опрос
не идёт.

Хранилище — память процесса (`src/lib/chat-store.ts`). История теряется при
перезапуске, а на Vercel инстансов функции несколько и они эфемерные, поэтому
у разных посетителей она может разойтись. Для чата на портфолио этого
достаточно; постоянное хранилище потребовало бы базы.

Кнопка видна всегда. Если сервер не отвечает, виджет показывает
«Подключение…» и продолжает попытки — исчезнуть он не может.

> Чат по `http` на IP в локальной сети (`http://192.168.x.x:3000` с телефона)
> работает: идентификатор клиента генерируется без `crypto.randomUUID()`,
> которого вне secure context не существует.

## PWA

Сайт устанавливается на телефон и компьютер: манифест (`src/app/manifest.ts`) и
service worker (`src/app/sw.ts`, собирается в `public/sw.js`).

Офлайн: страницы и статика кешируются, при потере сети показывается `/offline`.
`/api` не кешируется никогда. В `next dev` service worker отключён, чтобы не
прятать свежие правки.
